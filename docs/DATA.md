# 数据范围与复查条件

本发布包包含两轮实验的文档、研究源码、汇总统计、图表、配置与协议，以及用于对应证据的精选审计记录。两轮目录名称和内部相对位置保留，便于从[实验记录](实验记录.md)定位各轮材料。

## 已包含与未包含

| 材料 | 发布范围 |
|---|---|
| 报告、计划、方法说明、统计协议 | 包含；各轮报告保留开发与验证的区别 |
| 分析与绘图代码、执行源码、配置 | 包含源码快照；保留原有路径约定与守卫条件 |
| 首轮 `results/`、第二轮 `analysis/`、两轮 `figures/` | 包含汇总结果及图表；不等同于逐回合原件 |
| 审计、manifest 与 SHA 记录 | 保留用于说明证据来源、执行版本和检查范围的材料 |
| 第二轮 `models/` | 包含小型外部校准／线性读出 JSON；这些模型的拟合与拒绝部署过程见报告 |
| `source_snapshot/`、`evidence/` | 保留相关代码与版本证据；不改变上游内容的许可条件 |
| `raw/` | 仅保留说明 README；逐回合动作、物理状态、预测块、门控输入与分支原件未发布 |
| 完整模型权重、原始压缩归档、运行日志与临时产物 | 不包含；不包含原仓库 `.git` 历史及第三方大仓库 |

未发布材料包括逐回合 `.npz`／`.npy`／JSON／JSONL 原件、压缩归档、运行时状态、部署包、环境缓存及完整 SmolVLA／LAYA／官方参考模型权重。模型权重应依照各自上游说明和使用条件另行获取。本发布包没有提供原始实验数据的自动下载入口，也不承诺这些归档可公开下载。

## SHA 与审计记录怎样使用

各轮归档证明、模型／源码 manifest 和审计文件记录了来源 SHA256、运行版本与检查项。它们用于标识研究时使用的具体材料，并在持有相应原件时核对文件身份。发布包省略的大量原件无法仅凭 SHA 恢复，也不能仅凭检查项零错误推断策略有效。

原件 SHA 对应原始研究材料；公开整理时若调整文档路径或说明文字，相关文件字节会变化。应区分原件身份记录与公开副本，不把旧报告的哈希核验直接当作整理后整包的校验结论。

首轮结果与核验位于[首轮目录](../长动作块补充实验/)；第二轮的记录单位、证据用途及完成状态见[运行清单](../LAYA阈值诊断与优化/analysis/run_inventory.md)。报告中的原始文件路径仍具有定位含义，但对应原件可能不在本发布包内。

## 能复查到什么程度

可以直接检查公开的配置、控制逻辑、统计实现、汇总表和图表，并核对文档之间的数量与口径。逐动作来源审计、物理轨迹复现、反事实标签重算及部分 CPU 分析需要逐回合原始归档；summary 不含重建这些数据所需的全部信息。

执行源码保留原研究环境的路径及守卫，不是即装即跑的独立软件包。闭环重跑需要相应模型、LIBERO 资源、依赖版本和服务设置；原件分析也需按脚本预期布置输入数据。基础模型冻结不等于整轮没有拟合：外部校准与线性读出属于开发实验，未部署为正式控制器。

结果中的费用是指定口径下的模型服务时间，仿真逻辑延迟也不同于实测异步调度延迟。描述性区间、相同成功总数和审计通过，均不单独构成成功率不劣、总体等效或真实机器人加速的证明。
