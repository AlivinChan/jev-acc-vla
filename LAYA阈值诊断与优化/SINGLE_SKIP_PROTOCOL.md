# 单次跳过请求的闭环候选

登记时，完整state1校准分组和state2诊断分组尚未产生；已知训练state0有判定55/189，原紧凑二项偏向replan。此处固定新调度语义，不根据后续验证成绩修改。

每个新计划的请求时刻记为origin，I=round(0.3H)。计划年龄达到I时，用真正二项LAYA的argmax决定是否请求。若replan，请求在下一逻辑步交付、丢弃已过时的第0行，随后按新origin重复。若continue，本次请求跳过，在计划年龄2I时无条件请求；其间不再询问LAYA。有限队列边界仍强制请求。该策略让每次询问的年龄固定为0.3H，符合分支标签的局部干预窗口，但连续部署会改变后续状态分布，仍需实际闭环验证。

必须保留三类对照：原Smol70；始终跳过首个请求机会的固定0.6H请求（无LAYA）；未经适配的紧凑二项单次跳过门控。可选适配模型只能从CALIBRATION_PROTOCOL.md已登记的初筛中晋升；模型系数必须在state2评估前冻结。即使校准无效，原紧凑二项argmax仍可测试此调度。

实现资格检查：始终replan的单次跳过控制器与Smol70动作/物理轨迹逐值相同；始终continue与固定0.6H请求逐值相同；所有LAYA询问年龄恰为I，continue后至2I之间无额外请求，d=1与有限队列约束保持。实际模型闭环先用已曝光state0开发起点检查，不使用state10–14选择参数；最终候选再按VALIDATION_PROTOCOL.md同批配对验证。

适配模型必须单独标明“冻结LAYA主体＋新线性读出/校准”，保留原始LAYA logits、概率和实际部署概率，不能将适配输出冒称原始模型输出。费用必须包括特征捕获、读出、token审计和IPC；对比固定0.6H基线以判断LAYA是否真的贡献了决策价值。
