# 完整验证批次的跨H配对解释

在主验证尚未完整结束、尚未读取其汇总成绩时登记。所有执行条件和候选已冻结，本文件只规定同一完整cohort中的跨H汇总，不重选候选、不追加起点。

同一任务/初态配对比较H100−H50、H200−H50、H200−H100。主要解释对照为 `fixed45`：请求间隔固定45步、延迟与队列规则相同，只改变原生输出长度。其他在全部三种H均已登记的方法统一输出作补充，不按结果挑选。

Smol70及LAYA的检查周期或触发条件会随H变化，所以它们的跨H差异是“输出长度＋请求规则变化”的联合效果。K5对照的交付间隔仍固定5步。所有跨H比较均校验相同初始物理状态；H决定噪声形状，预先固定的噪声生成映射不变，不宣称整个不同长度张量相同。

报告完整配对成功数、胜/负、服务费用比及既有分层task/初态bootstrap区间。调用量和环境步数同时列出。不得把相同总成功数或包含零差异的区间解释为等效，也不得用这些结果再选择正式候选。该分析的描述性区间不作多重比较后的显著性保证。

实现只在拷贝的分析记录中将H键标准化，以便复用配对统计；原始记录、模型和实验配置保持不变。每一对的真实H另行保存。完整批次与审计的SHA都写入结果；未完成分片不得汇总。
