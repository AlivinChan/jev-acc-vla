# 冻结 VLA 的长动作块与 LAYA 门控实验

本仓库整理两轮研究实验的文档、源码快照、汇总数据与图表。研究问题是：在冻结 SmolVLA 的条件下，延长原生动作块，并让 LAYA 根据当前状态与剩余动作决定“继续执行／请求新计划”，能否减少模型调用，同时保持任务表现？

实验使用 LIBERO Spatial 仿真。底层 VLA 和基础 LAYA 权重保持冻结；第二轮另拟合了外部校准映射和线性读出，未将这些适配模型晋升为正式闭环控制器。这里保留开发过程、完整配对验证及未完成组的记录，不将回合数等同于独立初态数。

| 范围 | 主要内容 | 运行量口径 |
|---|---|---|
| 首轮长动作块实验 | 冻结 SmolVLA 原生输出 H=50／100／200；Smol70、LAYA 门控、固定 K5、同模型 VLASH 式对齐；另列官方模型参考 | 360 个主比较回合、90 个原始选择消融回合、30 个官方参考回合、12 个 pilot 回合 |
| 第二轮诊断与开发 | 输入数字格式、二选项与选项顺序诊断；检查周期和单次跳过策略；真实请求／跳过分支与外部读出 | 780 个新增开发闭环回合；564 个反事实机会／1128 条分支；离线判断另计 |
| 第二轮完整验证 | 主验证、费用接近固定周期、4 步与 5 步逻辑延迟 | 1050＋600＋450＋450＝2550 个方法／H 回合，四批分别统计 |
| 第二轮未完成对照 | 输入、动作行与噪声对齐；随机跳过 | 对齐组保留 619 条记录，其中完整两片 420 条用于部分描述，中止片 199 条单列；随机组 0／450，未启动 |

实验已经停止。未完成组不并入完整验证。d4 与 d5 共用配对初态；开发、资格检查、离线打分和分支轨迹也各有独立计数口径，详见[数据说明](docs/DATA.md)。

## 源码与复查条件

本仓库提供实验代码与上游源码快照。发布版已整理路径并删除非实验管理内容；模型、任务、控制规则、随机种子及汇总指标保留。运行前需要配置数据位置、模型缓存、服务进程与环境，并重新冻结代码、配置和运行资格检查。仓库未包装为一键独立重跑环境。

`EXPORT_MANIFEST.json`记录本发布版的文件指纹。实验收据中的历史源码和归档指纹仍对应原实验字节，用于追溯已完成的运行。

汇总 JSON、报告与图表可直接查阅。逐动作审计、反事实分支重算及部分 CPU 分析仍需要未随仓库发布的原始归档；仅有 summary 不能完整重现这些计算。GPU 闭环重跑还需要相应模型权重、仿真资源与软件环境，具体版本以各轮协议及源码快照为准。

计时指标主要为 VLA 与门控的同步服务时间。仿真在推理期间暂停，LAYA 使用仿真提供的对象信息；这些记录不能直接解释为真实异步机器人任务的加速倍数。官方 VLASH 参考使用不同模型与执行设置，在报告中单列。
